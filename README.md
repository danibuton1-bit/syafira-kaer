# Syafira Kaer

Bisa tidak buat website untuk pacar dan ada panel admin serta ada foto video di halaman utama yang di upload admin dan ada animasi animasi mengkilap di logo dan judul namanya 

Nama website nya : Syafira kaer

Warna desain bisa di ganti di panel admin pink merah muda hitam dan lain-lain 

Ada juga musik di halaman utama yang di panel admin dan musik berputar saat di buka di setiap halaman ada teks berjalan berwarna warni atau pink yang berjalan di atas dan itu juga bisa di atur oleh admin sesuai kecepatan nya
